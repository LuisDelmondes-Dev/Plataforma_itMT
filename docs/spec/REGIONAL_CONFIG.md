# Configuração regional do core

O core lê UF, nomes públicos, rótulos territoriais, endpoint/arquivo IBGE e quantidade esperada de municípios de configuração validada. O teste automatizado exercita Goiás sem alteração de código e rejeita código de UF inválido.

Procedência, publicação humana, isolamento tenant, auditoria e ausência explícita são invariantes e não podem ser sobrescritos pela região.
